Which recurrent network reads tourism demand best?

A Simple RNN, an LSTM, and a GRU were trained on identical 14-day windows of national daily tourist arrivals, under identical conditions, and scored on a held-out future period they never saw during training.

About this dataset

The source data tracks daily visits across 432 individual tourist-site combinations (54 areas × 8 facility types). This project sums all of them into a single national daily demand figure — a clean, interpretable signal with a clear weekly rhythm and a winter lull, ideal for testing how well each architecture captures recurring structure over time.
